# مسار — متابعة العملاء

تطبيق ويب خفيف (ملف HTML واحد) لمتابعة العملاء ومراحل التواصل، مع جولة عمل يومية وصندوق اقتراحات. جميع البيانات تُحفظ محلياً في المتصفح، والتطبيق **قابل للتثبيت ويعمل دون اتصال** (PWA).

## المزايا

- إدارة العملاء: القناة، المرحلة، وسيلة التواصل، الملاحظات، والصورة.
- مراحل واضحة من «أنوي التواصل» إلى «مكتمل» أو «مغلق».
- تذكير بمن يحتاج إلى متابعة حسب آخر تواصل.
- جولة يومية بمهام تتجدد كل يوم لكل قناة.
- كشف العملاء المكررين بالاسم أو وسيلة التواصل.
- وضع داكن/فاتح، وواجهة عربية من اليمين إلى اليسار.
- يعمل دون اتصال بعد أول زيارة، وقابل للتثبيت على الشاشة الرئيسية.

## التجربة محلياً

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

> يجب تشغيل التطبيق عبر خادم (لا عبر `file://`) حتى يعمل الـ Service Worker والتثبيت.

## التثبيت كتطبيق

- **Android / Chrome:** قائمة المتصفح ← «تثبيت التطبيق»، أو زر «تثبيت التطبيق» في القائمة الجانبية داخل التطبيق.
- **iPhone / Safari:** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **Windows / macOS / Chrome:** أيقونة التثبيت في شريط العنوان.

## النشر على GitHub Pages

1. اذهب إلى إعدادات المستودع ← **Pages**.
2. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`.
3. احفظ، وسيصبح التطبيق متاحاً على:
   `https://<username>.github.io/Massar-Daily-Clash-of-Clans/`

## بنية المشروع

| الملف | الوظيفة |
| --- | --- |
| `index.html` | التطبيق كاملاً (الواجهة والمنطق والتخزين المحلي) |
| `manifest.json` | بيانات التطبيق والأيقونات للتثبيت |
| `sw.js` | Service Worker: تخزين مؤقت للعمل دون اتصال |
| `icons/` | أيقونات التطبيق بمقاسات 192 و512 (عادية و maskable) وأيقونة iOS |

## ملاحظات

- البيانات محفوظة في `localStorage` على الجهاز نفسه؛ لا يوجد خادم أو مزامنة.
- عند تحديث التطبيق، غيّر قيمة `CACHE` في `sw.js` (مثل `massar-v1` إلى `massar-v2`) ليتخلص المستخدمون من النسخة القديمة المخزنة.
